МОЙ ПРОГРЕСС 2.0

В архиве:
- index.html — приложение
- manifest.json — установка на главный экран
- sw.js — офлайн-кэш

Для добавления на главный экран iPhone:
1. Разместите все три файла на HTTPS-хостинге статических сайтов (например GitHub Pages).
2. Откройте опубликованный адрес в Safari.
3. Нажмите «Поделиться» → «На экран Домой» → «Добавить».

Приложение хранит записи локально в браузере. Регулярно скачивайте резервную копию во вкладке «История».
Чтобы синхронизировать данные между устройствами, понадобится отдельный сервер/аккаунт — в этой версии синхронизации нет.
